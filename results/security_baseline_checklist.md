# 项目安全基线清单 (v1.0)

本文档定义了 `spam_classifier` 项目的基础安全配置标准，旨在遵循最小权限原则，保护数据、代码和模型的完整性与机密性。

---
### 1. 用户与组管理

- [x] **专用用户组**: 已创建 `ai_project` 用户组，用于统一管理项目权限。
- [x] **服务账户**: 已创建低权限服务账户 `spam_svc`，专门用于运行训练和部署任务。
- [x] **开发者账户**: 开发者账户（如 `xsq`）已加入 `ai_project` 组，以便于管理。

---
### 2. 文件系统权限 (`ls -l` 抽样)

| 路径                       | 所有者:组           | 权限模式 (数字/符号) | 安全说明                                     |
| -------------------------- | ------------------- | ---------------------- | -------------------------------------------- |
| `data/`                    | `xsq:ai_project` | 755 / `rwxr-xr-x`  | **数据只读**: 组内成员（含服务账户）只可读，不可写。 |
| `scripts/run_training.sh`  | `xsq:ai_project` | 775 / `rwxrwxr-x`  | **代码可执行**: 组成员可读可执行。           |
| `models/`, `results/`, `logs/` | `xsq:ai_project` | 775 / `rwxrwxr-x`  | **产出可写**: 服务账户需要写入权限。         |
| `configs/`                 | `xsq:ai_project` | 700 / `rwx------`  | **配置隔离**: 只有所有者可访问。             |
| `configs/settings.conf`    | `xsq:ai_project` | 600 / `rw-------`  | **密钥保护**: 只有所有者可读写。             |

---
### 3. 敏感信息管理

- [x] **配置与代码分离**: 敏感信息（如 API Key）存储在 `configs/settings.conf` 中，而不是硬编码在代码里。
- [x] **环境变量注入**: 通过启动脚本 (`run_training.sh`) 读取受保护的配置文件，并将敏感信息作为环境变量注入到运行时环境中。Python 代码通过 `os.getenv()` 获取配置。

---
### 4. AI 特定风险初步认知

- **模型窃取**: 核心模型文件（`.joblib`）的权限已被设置为非公开，防止被服务器上其他无关用户直接拷贝。
- **数据投毒**: 原始数据目录 (`data/`) 被设置为只读，防止服务进程被恶意利用时污染训练数据源。
